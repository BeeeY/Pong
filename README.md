Pong made with help from these tutorials:

https://gameidea.org/2024/10/05/make-pong-game-in-godot/ 

https://www.youtube.com/watch?v=Xq9AyhX8HUc

It's basically normal pong, it has a player v player mode, 3 bot modes, and a wall mode with just you and a wall.

Controls:

Player 1 / Red : w for up & s for down

Player 2 / Blue : arrow keys up and down

Installing: Download godot and flappy duck folder, use import button in godot, and select the flappy duck folder.
